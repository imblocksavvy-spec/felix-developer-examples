# Security

Do not include credentials, private keys, recovery codes, seed phrases, signatures, signed transactions, or funded account identifiers in an issue or pull request.

For a security report, use the private contact listed at [felix.trade/legal](https://felix.trade/legal). Never attach secrets or signing material. For normal integration questions, use the public documentation at [felix.trade/docs](https://felix.trade/docs).

Before any real-money workflow:

1. Confirm [runtime status](https://felix.trade/status).
2. Verify the active account and custody recovery state.
3. Preview the order and inspect fees, collateral, liquidity, and funding requirements.
4. Review the exact owner-signed limits.
5. Reconcile the resulting position and fill before taking another action.
